# Security policy

Chronicle stores conversation history and extracted memory locally. Please do
not post databases, raw event exports, access tokens, or private conversation
content in a public issue.

Report suspected security or privacy vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/indigokarasu/chronicle-agent-context-and-memory/security/advisories/new).
Include a minimal reproduction, affected version or commit, and expected impact.

General bugs and feature requests can use the public issue tracker.
